Introduction
The Rental Management System is a console-based application developed using the C programming language. The main purpose of this project is to help house or apartment owners manage tenant information in a simple and organized way. Usually, rental details are written down manually, which can take a lot of time and may lead to mistakes. This system reduces those problems by storing tenant data digitally and allowing easy access to it. It includes features such as tenant registration, login, rent management, record searching, and invoice generation, which make rental management more efficient and reliable.
Methodology
The system is developed using structured programming concepts in C. Tenant information is stored using structures, which help group related data such as name, phone number, flat number, and rent together. File handling is used so that the data remains saved even after the program is closed.
The application follows a menu-driven system and supports two types of users: Owner and Tenant. The owner can add, update, delete, and view tenant records. Tenants can log in to view their own information and generate rent invoices. This design keeps the system easy to understand and use.
Uses of the System
1. Helps house owners manage tenant information easily.
2. Provides separate login access for owners and tenants.
3. Reduces the need for manual paperwork.
4. Allows fast searching, editing, and deletion of tenant records.
5. Automatically generates rent invoices with discounts.
Limitations
Although the system is useful, it has some limitations. As it is a console-based application, it does not have a graphical user interface, which may be less user-friendly. The security is basic because passwords are stored as plain text. The owner has access to the tenant’s password, which compromises privacy.  The system also does not support online rent payments or multiple owners. There is no backup or recovery feature is the data file is accidently deleted .Additionally, fixed-size data storage limits the system when handling a large number of tenants.


Conclusion

The Rental Management System is a simple and effective tool for managing rental information. It shows how basic C programming concepts like structures, file handling, and functions can be used in real applications. Even though the system has some limitations, it successfully achieves its goal of organizing and managing tenant data efficiently. With future improvements such as better security, a graphical interface, and database support, the system can be made more advanced and user-friendly.
